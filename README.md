# Snektris · 贪吃蛇 × 俄罗斯方块

把游戏史上两款最经典的单人手机游戏——**俄罗斯方块（1984）**和**贪吃蛇（1976/诺基亚时代）**——融合进了同一块 10×20 棋盘：方块照常下落堆叠消行，一条蛇同时在方块缝隙间穿行觅食，堆错了还能让蛇把方块啃掉自救。这个组合证明了两款诞生近半世纪的经典玩法至今仍有新的化学反应，单文件、零依赖、手机可玩。

## 玩法

- **俄罗斯方块**：7 种标准方块自动下落，方向键 / 屏幕按钮控制移动、旋转、下落；消行得分，消行越多等级越高、下落越快。
- **贪吃蛇**：蛇按固定节奏自动前进，WASD / 在棋盘上滑动转向。吃到 🍎 得 50 分并变长 2 节。
- **融合点**：
  - 部分下落方块里藏着苹果（红框标记），落定后苹果留在棋盘上，需要操纵蛇爬上去吃；
  - 蛇撞进方块会把它**啃掉**（+10 分，蛇长 -1）——堆错形状时的救场手段，但啃多了蛇太短会死；
  - 蛇撞墙 / 撞自己会被罚 100 分并在底部重生；方块堆到顶则游戏结束。

## 操作

| 平台 | 方块 | 蛇 |
|---|---|---|
| 键盘 | ← → 移动，↑ 旋转，↓ 软降，空格硬降 | W A S D |
| 手机 | 底部按钮 | 棋盘上滑动 |

## 本地运行

无需构建，直接用浏览器打开 `index.html` 即可；或者起一个静态服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署到 GitHub Pages

```bash
git init && git add . && git commit -m "Snektris: snake x tetris mashup"
git branch -M main
git remote add origin https://github.com/<你的用户名>/snektris.git
git push -u origin main
```

然后在仓库 **Settings → Pages → Source** 选择 `main` 分支根目录，几分钟后即可通过
`https://<你的用户名>.github.io/snektris/` 在线游玩。
